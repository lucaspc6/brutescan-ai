# 🔐 BruteScan AI: Sistema Inteligente de Detecção de Acessos Suspeitos

Aplicação web com autenticação real e monitoramento inteligente de tentativas de login.
Registra logs de acesso (bem-sucedidos e falhos), gera arquivos CSV com os dados e os envia para agentes de IA que analisam e classificam os acessos como legítimos ou ataques por força bruta.
Inclui dois agentes detectores: um desenvolvido no Watson X e outro com Copilot, ambos gerando gráficos com vereditos baseados em modelos preditivos.

---

## 🎯 Objetivo

Prever ataques por força bruta com base em logs de IP, tentativas de login e padrões de acesso suspeitos.
